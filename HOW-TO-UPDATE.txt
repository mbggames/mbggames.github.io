MBG Games website - how updates work (November 2026)

The website is built from the files at the TOP of this repository (site.json, content/, tools/,
assets/, play/, privacy.html). The folder mbg-puzzles-site/ is an old copy and is NOT used -
do not upload anything into it.

Addresses:
  https://mbggames.com/                MBG Games home page (MBG Puzzles + Who Am I?), /sq/ ... /ko/
  https://mbggames.com/puzzles/        MBG Puzzles (11 languages: /puzzles/sq/ ... /puzzles/ko/)
  https://mbggames.com/puzzles/play/   web preview of the game
  https://mbggames.com/whoami/         Who Am I? (upload the game into a folder "whoami")
  https://mbggames.com/privacy.html    privacy policy (the link in Play Console stays the same)

Change something: open the file on github.com > pencil > Commit changes. 1-2 minutes later it
is online (Actions tab: "Publish website" turns green). Details: README.md.
